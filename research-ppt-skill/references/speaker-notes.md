# 讲稿（备注）与 Word 逐字稿

每页在内容JSON里写 `notes`，`dense_deck.py` 会写进PPT备注，`notes_docx.py` 导出Word逐字稿，并按每分钟240字估算每页用时。

## 原则：精炼、通俗，该讲清楚的绝不含糊

- **站在听众的角度讲**：先说这页想告诉大家什么，再讲证据，最后过渡到下一页。逻辑要连贯，听众不用看PPT也能跟上。
- **短句，口语化**：一句只讲一件事。用日常词，不堆形容词，不写长定语和嵌套从句。不照念页面上的文字，讲页面上没写的“为什么”和“所以呢”。
- **该科普的地方讲清楚**：
  - 关键概念第一次出现时，用一句话说明它是什么（例如：“典型气象年，就是从过去几十年里挑出最有代表性的月份，拼成的一年”）。
  - 方法的核心思想给一个打比方（例如：形态变换像给录好的旋律移调、放大音量）。
  - 听众是导师、同行专家时，CMIP6、SSP这类领域术语可以直接用，但仍要说清它在这里起什么作用。
- **数字要说出含义**：不只念数字，要说它说明了什么（例如：“二零六零年才明显拉开，说明越往后排放路径的影响越大”）。数字读法要好念，比如“三千零三十三个文件”。
- **诚实**：示意数据要在讲稿里点明；不夸大结论，不说材料里没有的东西。
- **删并页后重写，不拼接旧备注**：按新页唯一任务重新组织讲述，删除重复铺垫；逐项核对“左边/右下/三栏/四步骤/这张表”等指向，避免讲到已删除的图、表或独立文献页。正文与图片变动后重导Word并重新估算时长。

## 去 AI 味（页面短句和讲稿都过一遍）

听众听得出“模型写的”。先扫中文套路：

- **负向并列**：“不是 A，而是 B”“不仅…更…”→ 直接说 B。例：“不是疫苗不重要，而是靶点要选在不会变的地方”改成“疫苗仍然重要，但靶点要选在保守区”。
- **三项排比凑完整感**：“一条候选、一条评价链、一条边界” → 有几项说几项，改成具体名词或数字。
- **口号式断句**：“没有样品就没有评价”“设计再好，拿不到蛋白也没法评价” → 补主语，写成完整句：“先拿到蛋白，后面几项实验才有样品可用”。
- **段尾升华**：“真正可复用的是…”“说到底…”“回到核心…” → 停在事实上。
- **总结腔**：“创新不在单点，而在统一处理样品支撑起的完整比较链” → “5 条候选用同一批样品、同一套读出，差异才能归到设计上”；“这一步把设计变成了可测的实物” → “纯化后拿到 7 个样品，浓度 1.0–4.3 mg/mL”。
- **破折号、行内粗体标题、emoji**：全删；中文正文几乎不需要破折号。
- **数字后面补一句“说明什么”**：不要只念“6.857”，要说“在测试范围内最低”。
- **讲稿自然，但不编经历**：可以用“作者比较了…”“图中蓝线表示…”“我认为值得借鉴的是…”交代对象和评价；不要为了像人说话而虚构“我们当时担心…”等研究者心理或实验经历。页面小标题使用学术内容名，不写“说到哪里为止”“怎么读/所以呢”等写稿指令。

交付前把 `content.json` 的标题、引导句、要点和 `notes` 读一遍。装了 `humanizer` 技能就跑它的 `scripts/check_ai_tells.py`（路径按你的 skills 目录替换）：

```bash
python3 $SKILLS/humanizer/scripts/check_ai_tells.py <导出的txt>
```

没有 humanizer 就按上面的清单手查。命中逐条看上下文，不机械替换；页面短句和备注要分别改，不能只改讲稿。即使扫描零命中，也要逐句读标题、小标题和结论条，检查抽象总结、口号和反复的“不能/不要/先…再…”指挥口吻；改成具体方法、结果与适用条件。术语、风险限定和证据强度按科学含义保留，不为顺口改成过强结论。

## 篇幅

- **先按时长定总字数**：总字数 ≈ 汇报时长（分钟）× 240（含停顿可按 × 220 估）。再按页数分配：内容页一般 150–300 字，重点页可以更长；封面、目录 30–80 字；结束页收尾一句感谢或“请老师们批评指正”。两者冲突时以总时长为准。
- 超时就先删修饰和重复，再考虑删内容。
- **合并页的讲稿要重写，不拼接**：两页并成一页时，把原来两段按新页的四个块（图 / 判断 / 措施 / 结论）重新排成一段，字数取两段之和的 70–80%；保留的是事实与数字，删掉的是两段各自的开场与过渡。拼起来的两段在同一页会出现两次“这一页”“接下来”，一听就是补丁。
- 用 `\n` 分段，每段是一口气能说完的一个意思。导出的Word里每段单独成行，方便背诵。

## 结构模板（每页）

1. 一句话点出本页结论或问题。
2. 两到三句讲证据，指向页面上的具体图或表（“左边这张图……”）。
3. 一句解释含义，或者科普一个关键概念。
4. 一句过渡到下一页（可选）。
