# 版面与视觉规则

按内容层级选择组件；以当前用户稿为基准局部修改，不把参考参数当成所有页面必须套用的模板。

## 字号

阶梯固定：**12 / 14 / 18 / 19 / 20 / 21 / 26 / 72**（代码里是 `lib.FS`；正文 18 是用户 2026-11 定稿：18 合适，再大嫌大）

| 元素 | 字号 |
|---|---|
| 封面计划名 | 72 |
| 封面项目名 | 28 |
| 页眉编号 / 页标题 | 26 |
| 首结论（页顶，黑体+红词） | 20 |
| 尾结论（深蓝底白字） | 21 |
| 卡片标题 / 大编号 | 18–19 |
| **正文 / 卡片正文** | **18** |
| 分点小标题（比正文大一号） | 19 |
| 表格正文 | 16 |
| 次要标签、指标小字 | 12–14 |
| 图注 | 12 |

规则：
- 正文默认 16。**放不下就压条目（≤3 条）**，不要退回 13/14。
- 全局别用「统一 +1pt」的做法，要按层级给档位。
- 用户会手动放大某几处——下次以他的为准，别改回去。

## 对齐

- 「左标题 + 左正文」的卡片：序号圆、标题、正文三者左边界同一条线。这类文本框打 `la` 名字前缀，`tidy.py` 会跳过居中。
- 表格：所有单元格水平 + 垂直居中（长句也居中，用户明确要求）。
- 卡片内**不要分隔线**，删掉后靠留白分层。
- 文本框内容在框内**垂直居中**；短标签水平也居中。

## 首结论（页顶那条）

用户已定稿的形态（比早先「浅底 + 整句红字居中」更好，不要退回旧版）：

- 通栏**白底** + `#C1CCE4` 细边框（0.75pt）+ 小圆角；`x=0.42、w=12.5、h≈0.58、top≈0.93`。
- 左侧一个 **0.17 in 蓝色三角**做引导（`MSO_SHAPE.ISOSCELES_TRIANGLE` + `shape.rotation = 90`），文字框从 `x≈0.90` 起、**左对齐**贴住三角。
- 文字 **20pt 黑体加粗**，只有核心词标红 `#C00000`（每页 2–3 处），不整句红。
  `lib.judgment()` 只把 `【…】` 里的词染红：文本里一个标记都没写，整条就是黑字——这是刻意的，
  不要为了“看到红字”回到整句红字。
- 一句话说完、不超过一行；讲的是这一页的结论，不是标题重复。
- **不要**左右加竖杠（用户嫌丑）。
- 文本框名要以 `la` 开头（如 `la-jd`）：否则 `tidy.py` 会把 ≤28 字的短判断句水平居中，看起来像没和三角对齐。

## 颜色

- 主色 `#003195`；深 `#00205F`；浅底 `#F2F5FB`；边框 `#C1CCE4`；正文 `#1A1A1A`；灰 `#5A6A85`。
- 红色 `#C00000` 用于首结论与正文核心词；尾结论（深蓝底）用亮红 `#FF6060`，两处红不是一个色号。
- 不做整块实心红条；但**尾结论就是整条深蓝实心渐变**（白字），这是定稿形态，不要当成“整块实心条”删掉。
- 示意图不要高饱和拼色；要「接近真实」的颜色（油相琥珀、水相透明、微乳液乳白、玻璃透明）。

## 封面 / 结束页

- 封面：计划名（72）+ 项目名（26–28）+ 单位与时间。**不要**再放一行「XX 计划项目申报答辩」小字。
- **副标题两行必须手动断行、逐段居中**：靠自动换行会断成一长一短的孤行；`tplcore.set_text` 只设首段 `alignment`，第 2 段仍用模板的左对齐，渲染出来一行中、一行偏左，整体像楔形。正解：`COVER` 里直接写 `'第一行\n第二行'`，两行字数取接近（如 15/15），再遍历 `text_frame.paragraphs` 逐段 `PP_ALIGN.CENTER` + `line_spacing=1.35`。
- **封面信息块居中收口**：删掉模板自带的「汇报人：＿＿＿」胶囊后，下半幅会空成一片。用「居中细线（宽≈2.7 in、`#C1CCE4`）+ 居中的会议名/单位与时间（17pt）」压在波浪下方，比原来左对齐贴边稳。
- 结束页：感谢语 + 副句 + 单位与时间。不要再报身份、不要放汇报人胶囊（模板的「组合」胶囊要整组删）。
- 结束页的感谢语**新建文本框重绘**（感谢语 44pt 加粗白字 + 副句 30pt 淡蓝 + 一条 3 in 白色细分隔线），
  不要用 `set_text` 改模板那个原框：它自带的两段对齐不一致（一段偏左、一段居中），改完还是歪的，字号还会被继承成偏大一档。
  实测可用位置（13.333×7.5、蓝区约 0–5.0 in）：感谢语 `y≈1.72`、副句 `y≈2.72`、分隔线 `y≈3.56`，三样都水平居中。
- 封面/结束页的单位时间行也是重建文本框：模板里那一行的 run 带字间距（`spc`），
  `set_text` 保留字体属性会连字距一起留下，显示成「2026　 年　10　 月」。

## 目录页

- 目录**单列竖排**，项数随实际章节合并；八项参考稿可从行距 0.66、字号 19、序号圆 0.58、白底长条试排，不把八项固定为所有项目标准。
- 删掉模板页底部的装饰波浪图，页面下部留约 1/4 空白。
- 序号圆与长条沿用模板「高亮」那一套样式，别用灰的那套。

## 尾结论（页底那条）

形态：

- 整条**深蓝渐变**通栏（`#002A80 → #1F55B8`）、圆角，`top≈6.58、h≈0.64`；白字加粗 **21pt 居中**。
- 不再带「立论／方法／性能」这类左侧小标签——就是一句判断句。
- 关键短语用**亮红 `#FF6060`**：深蓝底上用 `#C00000` 会糊成一团，尾条的强调红要比正文红亮一档。
- 15 页正文里除确实排到底、没空间的页（如「现状 + 三条不足」），其余都带尾条；缺的那页由页内条目承担收束。

取舍：

- 先比较结论与正文，再判断空间：能明确研究启示、适用边界或优选原则时保留；仅重述正文、没有独立判断或挤占主体时不放。不要把可选组件处理成全稿统一添加或统一删除。
- 增量改稿只处理指定页面，不把弱化模板味理解为全稿批量删条。
- 按对象语义识别结论条，不以 `top >= 某坐标` 作为全稿删除条件，否则会误删图注、单位时间或预算说明。

## 正文重点标红：逐段人工指定，不要自动挑词

- 用户要求“很重要的词、句子、数字”都红出来，但**自动关键词匹配会挑错**：会漏掉真正要立的判断，也会把「乳化」「界面」「氢键」这类泛词或半截词标红，成段发红还会让页面变花。
- 做法：正文里用 `【…】` 标记，渲染时按段把 run 切开（红 = `#C00000` 加粗，其余保持原色原粗细）；每段 1–3 处，只标三类：①材料/方法的核心词；②关键数据（带单位）；③全篇最要紧的那句判断。
- 图注、指标小字、日期、单位时间一律不标。
- **自检**：导出 PDF 后扫括号残留；有残留说明某条 `para()` 没走富文本通道（常见于 `line=1.1` 这类没被批量替换的分支）。

## 分点：蓝色箭头 ➤ + 小标题大一号

用户已定稿（看参考稿截图点出来的，不是可选装饰）：

- 每个分点行首一个蓝色箭头 `➤`（与标签同色 `#003195`、加粗），随后紧接小标题。
- 小标题比正文**大一号**：正文 18 → 小标题 19；个别页放不下降到正文 16 时 → 小标题 17。`lib.bullets` 的 `{"label", "text"}` 写法自动处理。蓝色加粗，正文 `#1A1A1A` 常规。
- 一条分点 = 一个段落里的三个 run：`➤ `（蓝粗）+ `标签：`（蓝粗、放大一号）+ 正文（黑）。
  实现上先把三个 run 建好，再只把标签那个 run 的 `font.size` 改成 `Pt(size+1)`；不要整段放大，也不要把整段染蓝。
- 卡片内的条目同样带箭头；纯数字指标块、图注、页底结论条不加箭头。
- 分点正文框一律打 `la` 前缀：`tidy` 会把短文本水平居中，居中后“箭头—标签—正文”就不在一条左基线上了。

## 行距与段首缩进（中文正文）

- 中文正文行距 **1.44**（卡片内 1.40），段后 10pt（卡片内 8–10pt）。1.16–1.2 是英文正文的习惯，中文一挤就是「分点行距很不舒服」，用户会直接点出来。
- 分点段落必须带**悬挂缩进**：
  ```python
  pPr = p._p.get_or_add_pPr()
  pPr.set('marL', str(int(Inches(0.30))))    # 卡片内条目 0.18–0.22 in
  pPr.set('indent', str(-int(Inches(0.30))))
  ```
  没有它，第二行退回箭头下方，「箭头—标签—正文」看着参差；有它，换行文字与分点正文同一条竖线。
- 行距一改，**整页高度全部重算**：18pt × 1.44 一行约 0.36 in（16pt 约 0.32 in），比 1.16 时高约 25%。按「每条行数 × 条数 + 段后」估高，再把卡片、表格、图注、说明条整体下移；改完行距只靠目测必溢出。
- 放不下先**拆条或缩字**（每条 ≤20 字、≤3 条），再动容器高度，最后才降字号——降字号是用户明确反对的那个改法。

## 图位分级（大图 / 中图 / 小图）

生图之前先定级别与净尺寸再发需求；用户会把“没先想好大图中图小图”当成返工理由。

| 级别 | 用在哪 | 净尺寸（13.333×7.5 画布） | 图内文字密度 |
|---|---|---|---|
| 大图 | 背景页、单页主视觉 | 5.6×3.4 in 起 | 可多点铺陈、可带短标签 |
| 中图 | 意义页、成果页 | 5.4×3.2 in 起 | 少量短标签，一个主关系 |
| 小图 | 卡片内配图（3–4 列） | 3.67×1.40 in（3 列）／2.63×1.12 in（4 列） | **零文字**，只画关系 |

- 小图净高只有 1–1.4 in，需求里必须写“图内不要文字、每格独立、格间留白”；带文字的图缩到这个尺寸必然糊。
- 每张小图下补一个 9pt「示意」，满足“AI 图必须带示意”的图源核查；整页不必再设一条总图注。
- 卡片里塞不下时先删旁枝文字（「控制点」「工艺窗口」这类），改成「顶部小图 + 2–3 条主参数」；不要靠缩字号腾位置。
- 一组小图可让网页端画在**一张画布**上（2×2 四格或纵向三格）再按白缝切开；格宽不等分，按行扫近白列定切缝，不要按 `W//2` 均分。

## 卡片与图位的实测尺寸（排完先按这张表核，别靠目测）

括号里的数字都是 13.333×7.5 画布上的实测值，换内容时按同样的方法重算，不要把某一页的数值当全局常量。

- **三栏卡片里的两条要点撑不满卡**：4.07 in 宽的卡、正文框 3.67 in、15.5pt 两行，只占约 1.26 in；卡高写 2.18 in 会空掉 0.8 in（一眼就是“没排完”）。起排取**卡高 1.88 in、正文框 1.26 in**，下方同宽条目行高 0.74、步距 0.86 才铺到页底。
- **步骤卡的小图要高一点**：2.95 in 宽的步骤卡，图净高 **1.55–1.60 in**（等比后宽 2.2–2.5 in）才不显邮票；写 1.12 in 时宽只剩 1.5 in，投影上看不清画的是什么。卡高同步从 4.42 收到 4.15。
- **侧栏小卡别给太高**：「对比基准」这类 2.48 in 宽的说明卡，1.8 in 够用；2.3 in 会空掉半张卡。
- **18pt 下一行只有 9–10 字**（2.66 in 宽的卡内文字；16pt 时 10–12 字）：分点每条压到 ≤10 字，否则必出孤字——实测「…热压 1 / h」「…117.33 → 121.69 / MPa 。」「…只能降级回 / 收。」都是这么来的。判据行、图注行同样按 12–14 字断句，改法是换更短的词，不是缩字号。
- **红字按页计数**：正文红字（`#C00000`）每页 ≤4 处，尾条的 `#FF6060` 单独一档不计入；写完直接跑 `scripts/verify_deck.py`，它会报哪一页超了。两句判断挤在同一条首结论里（各标一个红词）+ 正文再标三处，就是 5 处，先撤最不关键的那个。

## 蓝色标题带与白色主体组件

1. 从当前稿中已认可的组件复制白色框体与蓝色渐变标题带，保留渐变方向、浅蓝细边线及圆角；按文字内容、几何位置和对象类型定位来源，不依赖未经核对的固定 shape 索引。
2. 先布置框体，再布置标题带，最后放标题与正文。复制 XML 后为新对象分配唯一 `cNvPr/@id`；将框体置于文字下层，避免后加的白色填充遮住正文。只复制装饰组件时不要连带旧文字、图片或图注。
3. 标题带可从高 `0.44–0.50 in`、白字 `19pt` 居中试排；主体白色，细边框 `#C1CCE4`，正文 `18pt`。标题与正文之间留空隙，不在卡片内部另加分隔线。
4. 创新点与关键问题双栏可从左宽 `≈7.15 in`、右宽 `≈5.12 in`、栏间距 `≈0.23 in` 试排，两个框体与标题带上下对齐；五项创新和三项问题按各自内容分配间距，不强迫行行对应。保留探索性标识，不为框体删掉必要条目。
5. 样式修改前后比较文字集合、图片内容及未涉及页的 slide XML 哈希；渲染核对正文边界，尤其较长条目不能因窄几个字符而出现单字尾行。

## 背景与意义合页：上大下小、背景三列

1. 先列出每张图证明的背景要点，逐一对应图、短标题与说明，再排研究意义。多图均属背景时，上方使用一个通栏“研究背景”蓝白组件，下方使用一个较矮的“研究意义”组件，不用左右背景/意义分区把图文关系割裂。
2. 对 `13.333 × 7.5 in` 画布，可从背景框 `x≈0.42、y≈0.99、w≈12.50、h≈4.25`，意义框 `y≈5.48、h≈1.72` 试排，标题带均高 `≈0.44 in`。尺寸随内容调整，不作为所有项目的固定模板。
3. 背景主体分三列，列起点可从 `x≈0.64、4.79、8.94`、列宽 `≈3.75 in` 试排；每列依次为等比图片、来源图注、短标题、两行左右的解释。净图位约 `3.75 × 1.96 in`，居中 fit，不拉伸。可从图片 `y≈1.62`、图注 `≈3.66`、短标题 `≈4.05`、正文 `≈4.54` 试排，逐图保持同层基线一致。
4. 意义区以理论、应用、育人等真实内容分列，每列一个短标题和一句书面说明；无需重复背景配图、实验路线或泛化结论。背景图不能单凭装饰性并排，就被解释为三项已证实的项目结论。
5. 删除与蓝色分区标题重复的旧标题、底色和页顶判断句时，按对象语义及局部范围处理；保留页眉、校徽和全部有效图源。最后渲染检查上方图文对应、下方留白和边界，再核对其他页未变。

## 现状与不足同页的空间分配

1. 保留国内外两列对照，先量四至五条正文所需高度，再缩短框体和正文框；不要只上移文字而保留大空框。
2. 在 13.333 × 7.5 in 画布上，可从现状框 `y≈1.62、h≈2.36`、正文 `y≈2.15、h≈1.67` 试排，正文 18pt（比 16pt 每行少约 1–2 字，框体要相应增高）；这些是起点，不是固定上限，换行增加时同步增高。
3. 将研究不足标题置于现状框下约 0.2 in，再排三行同宽条目。可从 `y≈4.86`、行距 `≈0.77`、条目高 `≈0.66` 试排；编号、短标题和说明各占固定列，说明列保持左对齐。
4. 使用浅底交替或开放留白区分条目，不另加卡内分隔线；避免三列窄说明造成参差换行。检查上方框底、下方标题、首行与末行的间距，整体平衡后再导出。

## 实验方案的分点与文字替换

- 每个实验模块通常三点，使用「体系对照：……」「参数扫描：……」「相态表征：……」一类语义标签；标签蓝色加粗、说明黑色常规，不把整条都设成强调色。行首统一带蓝色箭头 `➤`，标签比正文大一号——具体规格见上面的「分点：蓝色箭头 ➤ + 小标题大一号」。
- 以真实段落设置项目符号、行距与段后距；先压缩重复措辞，再调整容器，不用缩小正文字号换取卡片整齐。
- 重写多 run 文本时分别设置标签与正文样式；不要将首个项目符号 run 的样式复制给整段，否则正文会意外全部变蓝、加粗。替换后检查完整页面而非仅比较字符串。

## 预算图表的可读性

- 用原预算科目和金额生成可编辑环图，不重新分配预算来适应图形；表格、图表与总额必须同源核对。
- 隐藏环图图例时，用表格科目列的同色标记建立扇区映射；优先同一蓝色色阶，中心放总额与单位，旁边保留示例或批复口径说明。

## 图注

- 居中，压在图片正下方 0.03–0.05 in。
- 每张独立图片保留一条对应图注，多图页逐图标清来源；仅删除同一图片的重复标注，不能将其误解为全页最多一条。
