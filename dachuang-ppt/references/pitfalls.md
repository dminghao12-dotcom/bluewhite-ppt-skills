# 踩坑清单（这一轮申报答辩稿真实踩过的）

每条都是「现象 → 解法」，按出现频率排序。写新一页之前先扫一遍。

## 1. 用户在自己那份上改了东西，重建又长回来

现象：用户把稿子拿去改（删封面小字副标题、删结束页汇报人胶囊、删卡片分隔线、正文 14→16），下一轮我从脚本重建，这些删除全部复活，他会说「封面改回去」「上面你别动」。

解法：
1. 收到他改过的文件，**先 `cp` 成 `用户版/用户版-备份-HHMM.pptx`**，再在同一份上做增量改。
2. 定位他动过哪几页：逐页打印 `len(shapes)` / 图片数 / 文字数三个计数，计数变了的页才是他动过的；其余页不必逐页比。
3. 把改动写回生成脚本（整段删掉，而不是生成后再 `drop` 一次），重建后与他那份并排看。
4. **他删掉的东西与调大的字号同等有效，都是验收项。**

## 2. 「标题页太挤了、大气一点」不是封面

现象：说标题页，实际指第 2 页汇报提纲/目录（原话「标题页就是汇报提纲那个」）。按封面去改，白做一轮。

解法：目录 = 加行距（0.66）、单列竖排、删掉模板底部装饰波浪图；封面是否要改，单独问或另看一条。

## 3. 封面：删重复，不重画

模板原版封面（大号计划名 72pt + 项目名 28pt + 汇报人条 + 单位/时间）用户是接受的。他自己动手只删掉左上角那行与计划名重复的小字副标题。

所以**不要**改成「计划类型 17pt + 46pt 标题 + 短横线 + 副标题」那种四件式，他会说「封面改回去、这样挺好」。

只做两件事：文字压在白色波浪上就整块上移 0.3–0.5 in 回到蓝底；汇报人条一行放不下就降到 13.5pt，别让它折行。结束页同理：删重复副标题与汇报人胶囊，只留感谢语、校徽、单位时间。

## 4. 字号：16 是他亲手定的标准

他会亲手把正文 14→16、Q 条目 15→16、结论条 13.5→16。改完正文档位要逐页验溢出：**溢出靠删重复条目（≤3 条），不靠退回 14**。

## 5. 批量清残留形状，别把刚建好的也删了

现象：为清模板残留，按「无文字 + 在某区域」批量 `drop()`，结果把刚建的序号圆和长条一起删掉，页面只剩光秃秃标题。

解法：过滤条件必须同时限制**尺寸**（如 `width < 0.9 in` 才是圆点），并给自建形状命名（`shape.name = 'toc-c'/'toc-n'`），清理时跳过 `name.startswith('toc')`。删完必须看渲染图 —— `exit 0` 不能证明没删错。

## 6. 组件库的颜色参数只吃十六进制字符串

现象：`shape(..., fill=RGBColor(...))` 报 `TypeError: int() can't convert non-string with explicit base`。

解法：这类库的 `fill / line / color` 参数统一传 `'FFFFFF'`、`'C00000'`、`'5A6A85'`；只有直接写 `run.font.color.rgb = RGBColor(...)` 时才用对象。同一文件里不要两种写法交替。

## 7. 页眉编号框收窄 → 「3.2」折成两行

现象：把编号框从 0.7 收到 0.5 in 想让标题更靠左，渲染出「3.」换行「2」。

解法：26pt 下 `3.2`、`5.10` 需要 ≥0.9 in；标题位置由**起点**（1.34 in）决定，不由编号框宽度决定。

## 8. 卡片里加分隔线会被直接删掉

用户会删：卡片内靠序号圆与留白分层。三行按 1.30–1.40 in 等距排，间距自然拉开，不需要 `sline` 补视觉。

## 9. 模板页上的组织图/图标块，整组删

现象：模板「预期成果 → 总结与交流 → 四个小标签」加毛笔/印章图标，压在我们的大图上；只把标签文字换成我们的内容，得到「标签飘在图上、图标压着字」的半坏页，用户圈出来说「图片这一块我不喜欢」。

解法：这类装饰组织图与本项目内容无关，**整组删掉**（标签框、连线、图标块一起），只留内容大图 + 一行居中图注。

## 10. 先删形状再按索引取，必错位

`slide.shapes[i]` 是位置索引，`drop()` 之后后面全部前移，会出现 `IndexError` 或改到别的形状上。

解法二选一：先把要用的形状**对象**全部取出来再删；或把删除放到函数最末尾。删除后不要再用老索引。

## 11. 多列等宽卡片先算总宽，别边放边加

现象：四张步骤卡宽 3.02 in、x 每张 +3.42，第四张落到 13.70 in，直接出画布被裁掉一半（缩略图上才看得出来）。

解法：放之前先算 `n*w + (n-1)*gap ≤ 12.5`（画布 13.33、左右各留 0.42）。四列取 `w=2.95 / gap=0.22`；列间箭头宽算在 gap 里，不要另占一个卡位。批量生成后逐页看渲染图，越界只在第一版最容易被忽略。

## 12. 正文里的 ASCII 双引号会渲染成直角引号

现象：正文写 `"粘得牢"`，导出 PDF 里是直角引号，和全稿的中文标点不搭。

解法：在富文本渲染入口统一转全角，按出现顺序交替替换成 `“` 与 `”`（成对出现时不需要理解语义）。标点是这类稿子的验收细节，改一处即可全稿生效。

## 13. 表格下面再放一段说明，导出后与末行叠字

现象：`table(row_h=0.46)` 摆完，按「1.58 + 0.42 + 9×0.46」估算表底约 6.1 in，于是把“样品体系…”说明段放在 5.4 in；
实际渲染中单元格会因换行自动增高（长句单元格尤其），表底早已超过 6.1，两段文字直接叠成一圈黑影。

解法：**表页只放“表 + 尾结论”，表下不放任何说明段**——样品体系、测试标准这类内容并入表格行或挪到别页。
真要放就必须先渲染一版、量出表底再定位，并把 `row_h` 上调到 0.50–0.55 留出折行余量。

## 14. 图注按“框高”算位置，压到图片或尾条

现象：`picture(..., x, y, w, h, mode='fit')` 是把图等比缩放后**在框内居中**，实际图片高度由 `w/ar` 或 `h` 决定，
不等于框高；按 `y + h + 0.02` 放图注，遇到长得比框窄的图就把图注压在图上，遇到长图注就压到底部尾条。

解法：图注 y 用**框底 + 0.02**，并先算实际图高（`min(h, w/ar)`）；图注控制在**一行**（12pt 下 30 字以内），
“（资料图，论文图 5）“这种叠注删掉，出处只在交付说明里写。

## 15. 行内强调词被折行拆开

现象：`【无有机溶剂】`、`【大量含胶废水】` 这类 5–7 字的强调词正好落在行尾，渲染成“无有机溶 / 剂”、
“大 / 量含胶废水”，红色断成两截，比不标还难看。

解法：缩短到 4–6 字（`【无有机溶剂】`、`【含胶废水】`），或调语序让它落在行首/行尾之外；
改完必须看渲染图——字数一样但断行位置变了都会重新拆行。

## 16. 批量改渲染调用点，总有一种写法漏掉

现象：把 `para(b.text_frame, d, ...)` 逐个改成富文本版时，`line=1.14 / 1.12 / 1.18` 都换了，
唯独 `line=1.1` 那处没匹配上，页面上直接输出“【界面结合不足】”带括号的裸文本。

解法：两层保险。① 把标记解析放进**渲染入口**（`para`/`rich` 内部解析方括号），而不是每个调用点包一层；
② 无法改入口时，改完跑一次全文扫描：`any(c in page.get_text() for c in '【】')`，有命中就说明某条调用没走富文本通道。

## 17. 分点行距按英文习惯写，用户说「很不舒服」

现象：`para(..., line=1.16)` 配段后 7pt，中文分点两行之内挤成一片，块与块又分不清；换行后的文字退回箭头下方，整块参差。

解法：正文行距 1.44 / 卡片 1.40、段后 10pt，并给分点加 0.30 in 悬挂缩进（`marL` + 负 `indent`）。改完必须逐页重看——行距 +25% 会让原本刚好放下的卡片溢出，卡片高度、表格起点、说明条要跟着重算。规格见 `style-rules.md` 的「行距与段首缩进」。

## 18. 宽幅 AI 架构图的中文标签叠印／错字，缩略图看不出来

现象：让网页端画 12.3 in 宽的四段式架构图，缩略图很干净，放大才发现同一格里同一个词印了两层、或个别字被画成了别的字（一列六行标签最容易出）。

解法：收到图先**按列放大 3 倍逐条读标签**（`vision_analyze` 传 `region`），不要整图看着顺就贴。有叠印就回一句「第 N 列第 X 行同一个词印了两层，请把每列压到四行、每个标签四到六字」，重出通常一轮就好。个别错字可在本机原位补：按行取左右干净列的底色做线性插值填掉那一小段文字，再用 `Hiragino Sans GB` 按原字号重画正确的词，最后整图放大核一遍。

## 19. 论文原图当主视觉，投影上读不了

现象：论文图 1 是 1320 px 宽的四步流程图，铺到 9 in 宽时图内小字只剩 6–7pt，评审席上看不清——而它恰恰是「研究思路」这页最该被读懂的图。

解法：判据是**图内最小字号 × 放大倍数 < 9pt 就不当主图**。这类位置改让网页端按同一逻辑重画概念级架构图（四段，每段 3–4 个短标签），原论文图只在讲稿或补充材料里引用；不要靠裁切放大硬撑。
